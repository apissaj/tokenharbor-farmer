## Root cause

TokenHarbor embeds a Cloudflare Turnstile **managed** challenge on `/login?mode=signup`.
The form (`email`/`password` inputs) is hidden behind the challenge. After ~2 successful
registrations from one IP, Cloudflare requires the interactive challenge — which:

- **`requests`-based signup** cannot solve (no JS execution)
- **Headless browsers** (Camofox, Playwright stealth) auto-solve *invisible* mode only;
  once the IP is flagged, managed mode blocks them too
- **`ACTION_ID`** (`607ec2c1a962aa81ad67a2483c54b0cfadfda875b2`) remains **valid** — the
  blocker is Turnstile, not the Server Action endpoint
